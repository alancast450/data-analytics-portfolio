# Data Analytics Portfolio

## Association Rule Analysis

**Tools:** Python, Jupyter Notebook, pandas, mlxtend, Apriori

### Project Overview
Analyzed cosmetic purchase data to identify products that are frequently purchased together and uncover cross-selling opportunities.

### Analysis
- Prepared transaction data for association rule mining.
- Applied the Apriori algorithm to identify frequent itemsets.
- Evaluated association rules using support, confidence, and lift.
- Identified product combinations with strong purchasing relationships.

### Skills Demonstrated
Python • Data Mining • Association Rules • Apriori • Data Analysis
